# CODEFORGE Feature Roadmap

## v0.1.0 foundation
- Web + Capacitor Android app, landscape APK.
- Dark responsive workbench inspired by the project references.
- Explorer, tabs, Monaco editor, minimap, snippets and language file icons.
- IndexedDB workspace, Supabase email auth, cloud file sync and RLS migration.
- Guest warning and local identity.
- Workspace terminal commands, Pyodide Python, JavaScript Worker and sandboxed HTML preview.
- GitHub Actions for web build and debug APK artifact.

## v0.2 — platform integrations
- GitHub OAuth/App integration, repository picker, clone/status/branch/commit/push/pull.
- GitHub Actions workflow list, run/cancel, job/step logs and artifacts using least-privilege scopes.
- Native deep-link OAuth in Android.
- FCM device registration and a trusted sender function.
- Workspace export/import, conflict resolution and cloud quota dashboard.

## v0.3 — language runtimes
- Runtime manager and compatibility matrix.
- Additional local Android and desktop runners where technically viable.
- Language Server Protocol adapters for selected languages.
- Test discovery, debug adapters, breakpoints and run configurations.
- Package manager UI with per-runtime support reporting.

## v0.4 — extension platform
- Manifest and SDK specification.
- Publisher verification, signed packages, package integrity validation.
- Permission prompts and isolated extension host.
- Marketplace publishing, reviews, update channels and rollback.
- Compatibility checks and extension API versioning.

## Long-term
- Multi-root workspaces, split editors, remote collaboration, workspace templates, accessible themes, advanced search, refactorings, tasks, database explorer and team workspaces.
